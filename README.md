# DanloadchilnstaBot

ربات تلگرام برای دریافت لینک عمومی اینستاگرام و تلاش برای دانلود و ارسال ویدیو.

## راه‌اندازی روی Render

Environment Variable:
- `BOT_TOKEN` = توکن جدید ربات از BotFather

Build Command:
```bash
pip install -r requirements.txt
```

Start Command:
```bash
python bot.py
```

این پروژه برای لینک‌های عمومی طراحی شده و ممکن است در صورت تغییر محدودیت‌های اینستاگرام، بعضی لینک‌ها دانلود نشوند.
